# Board Game Achievements Tracker

A solo board game achievement tracker built as a single-file HTML app — no install required, works in any browser, and runs great as a PWA on iPhone.

Track plays, unlock achievements, and see your progress across a growing library of solo games.

## 🎮 Try it

👉 **[jessemurphy.github.io/boardgameachievements](https://jessemurphy.github.io/boardgameachievements)**

Add to your iPhone home screen via Safari → Share → Add to Home Screen for a full app experience.

## Features

- Log plays with game-specific fields
- Tiered achievements (bronze → silver → gold → platinum)
- Personal bests and near-miss indicators
- Achievement unlock dates
- Play notes
- Cross-game meta achievements
- Works offline, data stored locally on your device
